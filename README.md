# Odin Recipes

## Descripción
Este proyecto es una aplicación web estática construida como parte del plan de estudios de **The Odin Project**. Consiste en un sitio web de recetas estructurado únicamente con HTML semántico.

## Habilidades Demostradas
* Estructuración de documentos mediante HTML5 (`<!DOCTYPE html>`, `<head>`, `<body>`).
* Manejo de elementos de texto, encabezados (`<h1>` a `<h3>`) y listas (`<ul>`, `<ol>`).
* Construcción de enlaces relativos e hipervínculos navegables (`<a>`).
* Incrustación y optimización de imágenes locales con atributos `src` y `alt`.
* Control de versiones atómico y flujo de trabajo con Git y GitHub.
